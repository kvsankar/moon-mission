# Orion Visual References

Research date: April 3, 2026.

This point-in-time source-selection record informed the procedural Orion model.
It is non-authoritative research; current architecture lives in
[Orion Procedural Model](../../designs/rendering/orion-procedural-model-generation.md).

## Search Approach

1. Started with public-domain NASA Orion visual references.
2. Preferred orthographic renders because they expose proportions with less
   perspective distortion.
3. Selected views that show both body proportions and solar-array layout.
